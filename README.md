# SIRPY Web

This repository is a GitHub Pages port of the SIRPYv4 Spirit Island randomizer.

## Status
- Initial React/Vite scaffold created.
- Data loader and type definitions are in place.
- Core app shell confirms static data can be loaded and displayed.

## Next steps
1. Install Node.js and run `npm install` inside `sirpy-web`.
2. Run `npm run dev` to launch the app locally.
3. Implement the randomizer engine and the React UI for selection and generation.
4. Add localStorage persistence and profile save/load support.
